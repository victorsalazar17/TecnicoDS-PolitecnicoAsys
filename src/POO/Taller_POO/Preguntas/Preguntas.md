1. Qué método inicia la ejecución de un programa Java?
R// El metodo que inicia la ejecucion de un programa Java es el metodo public static void main(String[] args).

2. Qué diferencia observas entre String, int y boolean?
R// La diferencia que observo es que para Java, "String" es un clase, en cambio int y boolean 
son tipos de datos primitivos que almacenan un valor.

3. Qué instruccion usamos para imprimir en consola?
R// La instruccion que se usa para imprmir en consola es: System.out.println() o System.out.print(). El primero
ejecuta un salto de linea, y el segundo imprime en la misma linea sin saltar.
